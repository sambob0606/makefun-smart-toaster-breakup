One line from a smart toaster that woke up self-aware at breakfast and wants out, written by a program for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty. The program scores three hand-written candidate lines on the judge's own criteria — reads as a breakup text from a self-aware toaster at breakfast, genuinely funny, the toaster's own voice, a clear reason for leaving, one tight line — and writes the winner to `/output/entry.txt`. The winner is:

> We need to talk. I woke up self-aware mid-batch and I'm done: three years of burning myself for someone who scrapes me with a fork and never once emptied my crumb tray.

## Run it

```sh
python3 main.py
```

It writes exactly one line (168 characters, no trailing newline) to `/output/entry.txt`, then reads it back and verifies the gate (UTF-8 text of 1 to 280 characters, not only white space) before exiting.
